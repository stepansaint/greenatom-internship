# Java Backend Internship

This internship program is structured into specialized modules, preceded by an entry task.

The high-level **overview highlights only the primary core projects**. However, _additional sub-projects, architecture diagrams, and theoretical deep-dives_ are available directly within each individual module.

| Module | Core Project | Key Concepts |
| :--- | :--- | :--- |
| [Pre-Internship Task](src/main/java/com/entry_task) | **Palindrome & Bit-Swap**  | String processing, binary **bit-manipulation** operations, **SQL** |
| [Java Core](src/main/java/com/rosatom/java_se/core) | ***Console Battleship Game*** | **OOP** principles (abstraction, encapsulation, inheritance, polymorphism), matrix processing, **Functional Interfaces** |
| [Collections Framework & Reflection API](https://github.com/stepansaint/greenatom-internship/tree/main/src/main/java/com/rosatom/java_se/collections_exceptions_reflection) | ***Repeatable Executor & Limited Array*** | **Collections architecture**, Custom runtime annotations, **Stream API** |
| [I/O API](https://github.com/stepansaint/greenatom-internship/tree/main/src/main/java/com/rosatom/java_se/io_serialization_generics) | ***Console File Manager*** | Modern **NIO**, Regular Expressions, **Serialization Customization** |
| [Concurrency & JVM](src/main/java/com/rosatom/java_se/concurrency_jvm) | ***Custom Asynchronous Worker*** | Multi-threading foundations, **synchronization primitives** |
| [Persistence API](src/main/java/com/rosatom/jpa) | **DAO Implementations**  | Transactional lifecycle management, **JDBC** data architecture, **ORM**, **HQL**, **Criteria API** |
| [Spring Framework](src/main/java/com/rosatom/spring) |  ***Document Management System** is stored in a private GitHub repository* | **IoC & DI**, AOP, Automated Testing, **MVC & REST** services, Spring Security, **Spring Boot** architecture |
